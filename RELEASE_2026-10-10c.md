# Release 2026-10-10c – Mörkt läge "Sage First" (Lotuvi-riktlinjer v0.3)

**Önskemål (Mikael):** "Dark mode funkar inte" + riktlinjer v0.3, där mörkt läge är den enda ändringen mot v0.1.

**Vad som var fel:** temaväxlingen fungerade tekniskt (System, Ljust och Mörkt slog igenom på alla sidor), men det mörka uttrycket var orange-dominant på grafitgrått och följde inte v0.3. Knappar hade dessutom vit text inskriven i koden, vilket gör det omöjligt att använda en ljus accentfärg i mörkt läge.

## Vad som ändrats
| Område | Ändring |
|---|---|
| Mörk palett | Lotuvi Family Dark "Sage First" (v0.3 §09, Mockup A): mint `#6EE7B7` som primär (vald flik i bottenmenyn, +-knappen, primärknappar, länkar), coral `#FF7D66` som sekundär och sparsam, grön-charcoal ytor `#0F1412` (sida) / `#1A2020` (kort), kanter `#2A3230`, text `#F3F5F4` / `#A7B0AC`. |
| Text på accentknappar | Ny token `--on-accent`: vit i ljust, mörk `#0F1412` på mint i mörkt (12:1). Cirka 40 inskrivna `#fff` på accentytor bytta mot token; gradientknappar på Gå med i familj och i admin använder nu `--accent-bg`. |
| Pro-chippet | Egen token `--premium` (guldbrun i ljust, champagne i mörkt) – återanvänder inte Family-primary, enligt v0.3. |
| Webbläsarens temafärg | `#0F1412` i mörkt (även offlinesidan). |
| Ljust läge | Oförändrat. |

## Kontrast (WCAG)
Mörk text på mint 12,2:1 · mint på kort 10,8:1 · sekundär text på kort 7,4:1 · coral på kort 6,6:1 · Pro-chip 4,6:1 (ljust) / 10,3:1 (mörkt).

## Inte ändrat
Kalenderns typfärger, avatarfärger, mejlens färger, knapparnas pillerform. Inga databassteg.

## Att testa på mobilen
1. Inställningar → Utseende → Mörkt → Hem: mint på vald flik och +-knappen, mörk text på mint.
2. Kalender: dagens datum mint med mörk siffra; filterknappar läsbara.
3. Ny påminnelse: valda snabbdatum/upprepning är mint med mörk text.
4. Inköpslista, Uppgradera, Familj → lägg till: primärknappar läsbara.
5. Auto: telefonen i mörkt läge → appen följer; telefonen i ljust → ljust.
