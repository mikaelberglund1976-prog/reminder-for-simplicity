# Release 2026-10-07 – Klockslag + redigera aktiviteter och sysslor

**Önskemål (Mikael):** "Ex aktivitet så går det att lägga datum men inte vilken tid" och "när man går in på alla aktiviteter kunna uppdatera dem".

## Vilka funktioner som har tid
| Funktion | Tid | Varför |
|---|---|---|
| Aktiviteter | Start + valfritt slut (17:30–19:00) | Träningar, lektioner, möten har fasta tider |
| Påminnelser | Valfri tid (tandläkare 14:30) | Utan tid = heldag, som förut |
| Skola (prov/läxa) | Valfri tid (prov 08:20) | Läxor har sällan tid, prov ofta |
| Sysslor | Ingen | Görs "någon gång i dag" |
| Inköps-/önskelista | Ingen | – |

## Vad som ändrats
| Område | Ändring |
|---|---|
| `lib/reminderTimes.ts` (ny) | Tiden sparas i en självskapande tabell `reminder_times` (reminderId, startTime "HH:MM", endTime). Ingen rad = heldag. Väggklocka, så 17:30 förblir 17:30 över sommartid/vintertid. |
| `lib/timeFormat.ts` (ny) | Formatering/sortering för klienten. |
| `api/family/chores/[id]` (ny) | GET + PATCH: redigera en aktivitet eller syssla (namn, person, hur ofta, dagar, startdatum, tid, anteckning, godkännande). Barn får ändra sina egna aktiviteter men inte flytta dem till någon annan, och inte sysslor. |
| `dashboard/family/new` | Samma formulär används för att ändra (`?edit=<id>`). Aktiviteter: fält Börjar/Slutar + nytt val "En gång". |
| Aktiviteter-sidan | Tryck på en aktivitet → öppnas för redigering. Tiden visas ("Varje tisdag · 17:30–19:00"), listan sorteras efter tid. |
| Sysslor (Familj) | Tryck på namnet → öppnas för redigering. |
| Påminnelser | Klockslag i Ny/Ändra; visas på detaljsidan och Hem. |
| Skola | Klockslag när man lägger till/ändrar; visas i listan och på Hem. |
| Kalendern | Tid visas först, tidsatta poster sorteras först i klockordning. Aktivitet i kalendern öppnar redigering direkt. |
| Kalenderprenumeration (ICS) | Poster med tid blir riktiga tidsbokningar (Europe/Stockholm, VTIMEZONE); utan sluttid = 1 timme. Utan tid = heldag som förut. |

## Bra att veta
- **Inga databassteg.** Tabellen skapas av appen första gången (samma mönster som `school_feeds`, OPERATIONS §5a).
- En delad aktivitet (flera personer) är en kopia per person – redigering ändrar den kopia man öppnat.
- SchoolSoft-import tar inte med klockslag än.
- Påminnelsemejlen nämner inte tiden än.

## Att testa på mobilen
1. Aktiviteter → lägg till "Fotboll", tisdagar, 17:30–19:00 → syns i listan och kalendern med tid.
2. Tryck på aktiviteten → ändra tid/dag → Spara ändringar.
3. Familj → tryck på en syssla → ändra namn.
4. Ny påminnelse med tid 14:30 → syns på Hem och detaljsidan.
5. Skola → prov med tid 08:20.
6. Prenumererad kalender i telefonen (uppdateras inom några timmar) → aktiviteten ligger på rätt klockslag.
