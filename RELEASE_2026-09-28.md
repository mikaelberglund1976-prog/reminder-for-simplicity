# Release 28 sep 2026 – konton, radering, läxor, planer och reklam

Allt som låg pausat (se `ATT_GORA_PAUSAT_2026-09-27.md`) har slagits ihop med UI-reviewen (`UI_REVIEW_2026-09-27.md`). Planer (Free/Pro), provperiod och förberedelse för reklam och betalning har lagts till. Allt testades med påhittade familjer innan det gick live.

## Beslut (Mikael 28 sep)

| Område | Beslut |
|---|---|
| Gratis | Påminnelser, delad familj (bjuda in vuxna), **en** delad inköpslista, kalender + kalendersynk. Ett litet "Sponsored"-kort. |
| Pro | Barnkonton, sysslor, läxor & prov, önskelistor, aktiviteter, obegränsat antal inköpslistor, ingen reklam. |
| Provperiod | **14 dagar**, hela familjen, utan kort, en gång per familj. Startas av en vuxen med en knapp. Ersätter "1 barn, 7 dagar". |
| Uppgradera | Ingen betalning ännu. "I want Pro" skickar en förfrågan till admin (mail). Admin ger Pro i /admin → familjen: +14/30/90/365 dagar, valfritt antal dagar, "Forever" eller "Remove". Familjen får ett mail när Pro slås på. |
| Ångerrätt | Är inget val – den gäller enligt lag (14 dagar) när vi börjar ta betalt. Provperioden är produktbeslutet. |
| Betalning senare | Databasen är förberedd: `proUntil`, `plan`, `proSource`, `stripeCustomerId`, `stripeSubscriptionId`. All logik för vem som har vad finns på ett ställe: `app/src/lib/entitlements.ts`. |
| Radering | Allt som personen var ansvarig för ligger kvar men blir "Unassigned" **direkt** (påminnelser, sysslor, läxor, överlämningar). Presenter som personen reserverat blir lediga igen. Personens egna saker (t.ex. önskelista) göms och kommer tillbaka om kontot återställs inom 60 dagar. Vid återställning sätts personen inte tillbaka som ansvarig. |
| Reklam | Bara för **vuxna på gratisplanen**. Aldrig för barn (DSA + svensk marknadsföringslag), Pro, provperiod eller reklamfria familjer. Egna annonser i /admin/ads – ingen annonsnätverks-spårning och ingen cookie-banner behövs. Vi räknar bara visningar och klick per annons. |
| Köpa sig fri | Pro tar bort reklamen. Ett separat "reklamfritt" läge finns förberett (`adFreeUntil`, knapp i admin → familjen) för ett eventuellt billigare tillägg senare. |

## Testat (lokalt, med testdatabas)

Familjer: **Lindqvist** (Pro, 2 vuxna + 2 barn), **Nyberg** (gratis, 2 vuxna), **Berg** (provperiod pågår), **Ek** (provperioden slut), **Nina** (utan familj), ny användare **Greta** (registrering).

81 automatiska kontroller, alla gröna, bland annat:
- Gratis: en inköpslista fungerar och delas med partnern; lista nr 2, önskelistor, barn och sysslor spärras på servern (inte bara i gränssnittet).
- Provperiod: startar på 14 dagar, kan inte startas igen, låser upp allt inklusive nya barn.
- Provperioden slut: "Your free trial has ended" → "I want Pro" → admin ger 30 dagar → upplåst; förlängning läggs på slutdatumet; "Remove" tar bort.
- En vanlig användare kan inte ge sig själv Pro eller skapa annonser.
- Radering: medlem ber om radering → admin godkänner → kan inte logga in, tilldelningar borttagna, sakerna kvar, reservation släppt, önskelistan gömd → admin återställer → allt tillbaka utom tilldelningarna.
- Registrering → mail → bekräfta → admin godkänner → inloggning. Barnkonto → länk → välj lösenord → hamnar i barnvyn ("My week").
- Reklam: gratis-vuxen ser kortet, barn/Pro/provperiod/reklamfri ser inget, klick räknas och skickas vidare, länkar som inte är http(s) nekas.
- Ljust och mörkt läge på alla nya sidor.
