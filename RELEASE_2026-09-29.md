# Release 29 sep 2026 – barnkonton med eget konto/Google + GDPR-åtgärder

Två omgångar samma dag. Båda live via VS Code "Sync" → Vercel.

## 1. Barn som redan har ett konto, och Google (commit `59d4e40`)

Detaljer i tillägget längst ned i `RELEASE_2026-09-28b.md`. Kort: man kan inte söka upp en familj; en förälder lägger till barnet med e-post. Finns kontot redan skickas en inbjudan och kontot blir ett barnkonto vid nästa inloggning (lösenord eller Google). Inbjudna slipper admin-godkännandet. Logik: `app/src/lib/invites.ts`.

## 2. GDPR-åtgärder (från GDPR-genomgången, se `GDPR.md`)

| Åtgärd | Vad som ändrades | Filer |
|---|---|---|
| Data stannar i EU | Serverfunktionerna körs i Frankfurt (`fra1`), samma region som databasen | `app/vercel.json` |
| Bilder raderas med personen | Profilbilden tas bort när kontot rensas efter 60 dagar; daglig cron tar bort bilder vars person/familj inte finns kvar | `lib/accountDeletion.ts`, `lib/media.ts` (`purgeOrphanMedia`), `lib/cron.ts` |
| Komplett dataexport | Exporten innehåller nu även läxor/prov, sysslor och aktiviteter som andra lagt in åt dig, dina avbockningar, idéer och röster samt profilbilden | `api/profile/export/route.ts` |
| Inga onödiga Google-tokens | Googles access-/id-token sparas inte längre; gamla nollställs av cron | `lib/auth.ts`, `lib/cron.ts` |
| Inga anrop till Clearbit | Logotyper ersatta med initialer i varumärkesfärg – användarens IP skickas inte längre till USA | `dashboard/page.tsx`, `dashboard/[id]/page.tsx` |
| Vårdnadshavarens bekräftelse | Kryssruta när ett barn läggs till (krävs av API:t). Sparas i ny tabell `parental_consents` (vem, när, version). Barn från före idag: "Confirm as guardian" på Family members | `lib/consent.ts`, `lib/consent-version.ts`, `api/family/consent`, `api/family/child-profiles`, `dashboard/family/members` |
| Barnversion av integritetstexten | "What does the app save about me?" längst ned i My week | `dashboard/family/child/page.tsx` |
| Integritetsmeddelande publicerat | `/privacy` omskriven och publicerad (version 2026-09-29), länkad från registrering, Settings och ☰-menyn | `app/privacy/page.tsx`, `register/page.tsx`, `profile/page.tsx`, `HamburgerMenu.tsx` |
| Åldersgräns för egen registrering | Registreringssidan: 13 år för eget konto, yngre läggs till av förälder | `register/page.tsx` |
| En väg att lägga till barn | "+ Add child" i Settings leder nu till Family members (där kryssrutan finns) | `profile/page.tsx` |

**Databas:** ny tabell `parental_consents`, skapas automatiskt vid första användning (`CREATE TABLE IF NOT EXISTS`), samma mönster som `media_images`. Ingen manuell åtgärd, inga nya miljövariabler.
