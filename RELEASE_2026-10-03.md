# Release 3 okt 2026 – SchoolSoft-import per barn, Home först, prov på Home

Bygger på `RELEASE_2026-10-01.md` (barnets startsida, ta bort familjemedlemmar, samma bild överallt, Home längst till vänster). Allt nedan live via push till `master` → Vercel.

## 1. SchoolSoft-import per barn (nytt)

**Mikaels beslut:** en prenumerationslänk per barn; bara en vuxen lägger upp den och väljer barn; synk max en gång per dag; info om vad man ska välja i SchoolSoft-appen; importerade saker hålls isär från manuella och kan tas bort med ett tryck så man kan synka om med annat urval; man ska kunna justera dem.

| Del | Hur | Filer |
|---|---|---|
| Koppla | School → kortet **SchoolSoft** → **Connect** på barnet → klistra in länken från SchoolSoft. Kortet syns bara för vuxna med Pro/provperiod | `components/SchoolSoftCard.tsx`, `dashboard/school/page.tsx` |
| Guide i appen | Schema & Kalender → Exportera kalender → Hantera innehåll: **på** Uppgifter, Planeringar, Kalenderhändelser; **av** Schema; Tidbokningar valfritt; kopiera länken under "Prenumerera på kalender". Plus SchoolSofts varning om att alla med länken kan se kalendern | `SchoolSoftCard.tsx` |
| Bara vuxna | API:t kräver OWNER/PARENT/ADULT för koppla, byt länk, Sync now, Remove imported, Disconnect. Länken skickas aldrig till webbläsaren (bara värdnamnet). Barn kan inte ta bort eller skriva om importerade poster | `api/family/school-feeds/*`, `api/family/school/[id]` |
| Synk | En gång per dag i den dagliga cron-körningen (08:00 UTC, före påminnelserna). "Sync now" för vuxna, max var 10:e minut. Hämtar 14 dagar bakåt – 120 dagar framåt | `lib/schoolFeeds.ts`, `lib/cron.ts`, `api/cron/send-reminders` (maxDuration 60 s) |
| Tolkning | Läser VEVENT och VTODO. Prov om rubriken innehåller t.ex. prov/test/förhör/glosförhör/diagnos/NP; läxa om läxa/uppgift/inlämning (eller en VTODO); annars "Other". Ämne gissas från svenska ämnesnamn (Matematik → Maths …). Inställda (CANCELLED) hoppas över | `lib/schoolFeeds.ts` |
| Isär från manuella | Ny tabell `school_imports` kopplar varje importerad post till kalenderns UID. Posterna märks **SchoolSoft** i listan | `lib/schoolFeeds.ts`, `SchoolSection.tsx` |
| Ta bort alla importerade | Knappen **Remove imported** per barn – bara importerade försvinner, egna ligger kvar. Sedan "Sync now" för att hämta igen | `clearImported()` |
| Justera | Tryck på en post (alla skolposter, inte bara importerade) → ändra typ, ämne, namn, datum. En ändrad importerad post skrivs inte över vid nästa synk. En borttagen kommer inte tillbaka | `SchoolSection.tsx`, `api/family/school/[id]` |
| Borttagna i SchoolSoft | Försvinner här vid nästa synk, om ingen ändrat eller bockat av dem och de inte redan passerat | `syncFeed()` |
| Mejl | Importerade poster mejlar bara barnet dagen före (inte föräldern som kopplade, som annars fått ett mejl per läxa) | `lib/cron.ts` |
| Säkerhet | Bara länkar på `*.schoolsoft.se` hämtas (servern hämtar det som klistras in – annars kunde vem som helst få servern att anropa godtyckliga adresser). Omdirigering bort från SchoolSoft avvisas. 12 s timeout, max 3 MB | `normalizeFeedUrl()`, `fetchFeed()` |
| GDPR | Ny rad i `/privacy` (vad + rättslig grund) och en punkt under Barn. Länk och import-bokföring raderas när barnkontot rensas | `privacy/page.tsx`, `lib/accountDeletion.ts` |

**Databas:** två nya tabeller, `school_feeds` och `school_imports`, skapas automatiskt vid första användning (samma mönster som `media_images`). Ingen `db push`, inga nya miljövariabler.

**Inte testat mot riktig SchoolSoft:** vi har inte sett en riktig fil från SchoolSoft än. Tolkningen är testad mot en egen exempelfil i SchoolSofts stil. Fungerar inte prov/läxa-gissningen på riktiga data: skicka en ICS-fil (SchoolSoft → "ICS KALENDER FIL") så justeras reglerna. Typen kan alltid ändras för hand.
